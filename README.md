# The 3AM Fridge Text

[![make.fun · u-deysumbrella-the-3am-fridge-text-4c3e721d](https://make.fun/badge/u-deysumbrella-the-3am-fridge-text-4c3e721d.svg)](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d)

One line (115 characters) that a smart fridge would text its owner at 3am,
written by a program to `/output/entry.txt`. Node 22, standard library only.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```

## The line

> It's 3am. You've opened me 11 times tonight and taken nothing. The leftover pizza has filed a complaint. So have I.
